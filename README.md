# Учебный проект по Python 
---

## Тестирование

Проект полностью покрыт модульными тестами с использованием фреймворков `pytest` и `pytest-cov`.

## Документация проекта
Полное описание проекта находится
**[Здесь](docs/docs.md)**

### Что протестировано:
- **Модуль `masks`**: проверка корректности маскировки карт различной длины и счетов.
- **Модуль `widget`**: тестирование маскировки входных данных разного формата и преобразования дат ISO.
- **Модуль `processing`**: фильтрация по статусам и сортировка списка транзакций по дате (по возрастанию и убыванию).
- **Модуль `generators`**: проверка фильтрации по валютам, генерации описаний и форматирования номеров карт в заданной диапазоне.

 В тестах активно используются **фикстуры** (для подтягивания тестовых данных) и **параметризация** (для проверки граничных значений и различных сценариев).
