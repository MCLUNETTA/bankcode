# Документация проекта

## Модуль `generators`

Модуль содержит генераторы для работы со списком банковских транзакций: фильтрации по валюте, получения описаний операций и генерации номеров банковских карт.

### `filter_by_currency`

```python
filter_by_currency(
    transactions: list[dict],
    currency_code: str = "USD"
) -> Iterator[dict]
```

Фильтрует список транзакций по коду валюты.

Функция последовательно перебирает переданные транзакции и проверяет код валюты внутри поля `operationAmount.currency.code`. В результате возвращается генератор, выдающий только те транзакции, валюта которых соответствует переданному коду.

**Параметры:**

* `transactions` — список словарей с данными о транзакциях.
* `currency_code` — код валюты для фильтрации. По умолчанию используется `"USD"`.

**Возвращает:**

`Iterator[dict]` — итератор отфильтрованных транзакций.

**Пример:**

```python
transactions = [
    {
        "operationAmount": {
            "currency": {
                "code": "USD"
            }
        }
    },
    {
        "operationAmount": {
            "currency": {
                "code": "EUR"
            }
        }
    },
]

usd_transactions = filter_by_currency(transactions, "USD")

for transaction in usd_transactions:
    print(transaction)
```

### `transaction_descriptions`

```python
transaction_descriptions(
    transactions: list[dict]
) -> Iterator[str]
```

Возвращает описания транзакций по одному.

Функция перебирает список транзакций и извлекает значение поля `description`. Если поле отсутствует, возвращается пустая строка.

**Параметры:**

* `transactions` — список словарей с данными о транзакциях.

**Возвращает:**

`Iterator[str]` — итератор с описаниями транзакций.

**Пример:**

```python
transactions = [
    {"description": "Перевод на карту"},
    {"description": "Оплата покупки"},
]

descriptions = transaction_descriptions(transactions)

for description in descriptions:
    print(description)
```

### `card_number_generator`

```python
card_number_generator(
    start: int,
    stop: int
) -> Iterator[str]
```

Генерирует номера банковских карт в диапазоне от `start` до `stop` включительно.

Каждый номер преобразуется в 16-значную строку с ведущими нулями и форматируется в виде четырёх блоков по четыре цифры:

```text
XXXX XXXX XXXX XXXX
```

**Параметры:**

* `start` — начальный номер диапазона.
* `stop` — конечный номер диапазона. Значение включается в диапазон.

**Возвращает:**

`Iterator[str]` — генератор форматированных номеров карт.

**Пример:**

```python
numbers = card_number_generator(1, 3)

for number in numbers:
    print(number)
```

Результат:

```text
0000 0000 0000 0001
0000 0000 0000 0002
0000 0000 0000 0003
```

## Модуль `masks`

Модуль содержит функции для маскировки номеров банковских карт и счетов.

### `get_mask_card_number`

```python
get_mask_card_number(card_number: str) -> str
```

Маскирует номер банковской карты.

Первые шесть цифр номера остаются видимыми, следующие шесть цифр заменяются символами `*`, а последние четыре цифры остаются открытыми. Номер разделяется на блоки по четыре символа.

**Параметры:**

* `card_number` — номер банковской карты в виде строки.

**Возвращает:**

`str` — замаскированный номер карты.

**Пример:**

```python
get_mask_card_number("1234567890123456")
```

Результат:

```text
1234 56** **** 3456
```

---

### `get_mask_account`

```python
get_mask_account(card_number: str) -> str
```

Маскирует номер банковского счета.

Все символы номера, кроме последних четырёх, заменяются двумя звёздочками. В результате отображаются только последние четыре цифры номера.

**Параметры:**

* `card_number` — номер банковского счета в виде строки.

**Возвращает:**

`str` — замаскированный номер счета.

**Пример:**

```python
get_mask_account("1234567890123456")
```

Результат:

```text
**3456
```

## Модуль `processing`

Модуль содержит функции для обработки списка банковских операций: фильтрации операций по статусу и сортировки операций по дате.

### `filter_by_state`

```python
filter_by_state(
    data_list: list[dict],
    state: str = "EXECUTED"
) -> list[dict]
```

Фильтрует список словарей по значению ключа `state`.

Функция перебирает все элементы переданного списка и добавляет в результат только те элементы, значение ключа `state` которых совпадает с переданным значением.

По умолчанию выбираются операции со статусом `"EXECUTED"`.

**Параметры:**

* `data_list` — список словарей с данными об операциях.
* `state` — значение статуса, по которому выполняется фильтрация. По умолчанию `"EXECUTED"`.

**Возвращает:**

`list[dict]` — новый список, содержащий только элементы с указанным статусом.

**Пример:**

```python
operations = [
    {"id": 1, "state": "EXECUTED"},
    {"id": 2, "state": "CANCELED"},
    {"id": 3, "state": "EXECUTED"},
]

executed_operations = filter_by_state(operations)

print(executed_operations)
```

Результат:

```text
[
    {"id": 1, "state": "EXECUTED"},
    {"id": 3, "state": "EXECUTED"}
]
```

Для фильтрации по другому статусу можно передать его явно:

```python
canceled_operations = filter_by_state(
    operations,
    state="CANCELED"
)
```

### `sort_by_date`

```python
sort_by_date(
    data_list: list[dict],
    descending: bool = True
) -> list[dict]
```

Сортирует список словарей по значению ключа `date`.

Функция использует встроенную функцию `sorted()` и возвращает новый отсортированный список. Исходный список при этом не изменяется.

По умолчанию сортировка выполняется по убыванию даты — от более поздних операций к более ранним.

**Параметры:**

* `data_list` — список словарей с данными об операциях. Каждый словарь должен содержать ключ `date`.
* `descending` — определяет направление сортировки:

  * `True` — по убыванию, используется по умолчанию;
  * `False` — по возрастанию.

**Возвращает:**

`list[dict]` — новый список, отсортированный по дате.

**Пример сортировки по убыванию:**

```python
operations = [
    {"id": 1, "date": "2023-01-15"},
    {"id": 2, "date": "2024-03-10"},
    {"id": 3, "date": "2022-12-01"},
]

sorted_operations = sort_by_date(operations)

print(sorted_operations)
```

Результат:

```text
[
    {"id": 2, "date": "2024-03-10"},
    {"id": 1, "date": "2023-01-15"},
    {"id": 3, "date": "2022-12-01"}
]
```

Для сортировки по возрастанию необходимо передать `descending=False`:

```python
sorted_operations = sort_by_date(
    operations,
    descending=False
)
```

## Модуль `widget`

Модуль предоставляет функции верхнего уровня для форматирования банковских данных: маскировки номеров карт и счетов, а также преобразования дат.

### `mask_account_card`

```python
mask_account_card(info: str) -> str
```

Маскирует номер банковской карты или счета в зависимости от переданного типа.

Функция разделяет исходную строку на название объекта и его номер. Если название начинается со слова `"счет"`, используется маскировка банковского счета. Для остальных типов используется маскировка номера карты.

Название объекта сохраняется без изменений.

**Параметры:**

* `info` — строка, содержащая название карты или счета и номер.

**Возвращает:**

`str` — строка с замаскированным номером.

**Пример для банковской карты:**

```python
mask_account_card("Visa Platinum 1234567890123456")
```

Результат:

```text
Visa Platinum 1234 56** **** 3456
```

**Пример для счета:**

```python
mask_account_card("Счет 1234567890123456")
```

Результат:

```text
Счет **3456
```

### `get_date`

```python
get_date(date_string: str) -> str
```

Преобразует дату из строки с датой и временем в формат `ДД.ММ.ГГГГ`.

Функция извлекает часть строки до символа `T`, разбирает дату по компонентам года, месяца и дня и возвращает её в формате:

```text
ДД.ММ.ГГГГ
```

**Параметры:**

* `date_string` — строка с датой в формате, содержащем дату до символа `T`, например `YYYY-MM-DDTHH:MM:SS`.

**Возвращает:**

`str` — дата в формате `ДД.ММ.ГГГГ`.

**Пример:**

```python
get_date("2024-03-11T02:26:18.671407")
```

Результат:

```text
11.03.2024
```
